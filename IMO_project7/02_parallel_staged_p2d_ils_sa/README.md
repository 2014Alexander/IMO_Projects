# 02_parallel_staged_p2d_ils_sa

Projekt zawiera równoległy wariant algorytmu `STAGED_P2D_15_35_55_75 / ILS-SA` użyty w zadaniu 7.

## Uruchomienie

```bash
./run_parallel_staged_ils_sa.sh 0.5 200 20260614 configs
```

Wyniki zostaną zapisane do katalogu:

```text
out_parallel_staged_ils_sa_0.5s
```

Porównywane warianty używają liczby wątków:

```text
1, 2, 4, 8
```
